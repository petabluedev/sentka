# 🚛 Sentka — Modern Auto-Logistics Platform

Sentka is a next-generation logistics platform that connects **shippers and drivers** across the U.S. auto transport industry — built for **speed, automation, and transparency**.  
It simplifies how vehicles move from **auctions → carriers → dealers → end customers**, combining marketplace flexibility with powerful P2P features.

---

## 🌍 Vision
To build the **most intelligent logistics backbone** for auto transport — empowering small carriers, dispatchers, and brokers through AI, automation, and real-time visibility.

---

## ⚙️ Core Features
- **P2P Load Board** – Drivers and shippers connect directly without middlemen  
- **3-Minute Onboarding** – Instant signup, KYC verification, and dispatch readiness  
- **Smart Bidding** – Dynamic pricing that matches loads to the nearest qualified driver  
- **Live Tracking** – Real-time GPS visibility and automated status updates  
- **Instant Payouts** – Verified delivery triggers same-day driver payments  
- **SpeedFee Integration** – Escrow-backed transactions for trustless settlements
